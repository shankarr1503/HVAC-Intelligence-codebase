# Contributing to HVAC Intelligence

Thank you for your interest in contributing to this project! We welcome code,
documentation, bug fixes, and new ideas.

1. Fork the repository and create a feature branch.
2. Ensure new code includes tests and adheres to existing style (PEP8).
3. Update documentation in `/docs` as needed.
4. Run `pytest` to verify tests pass.
5. Submit a pull request describing your changes.

Please adhere to the code of conduct and maintain a respectful tone when
interacting with maintainers and other contributors.
